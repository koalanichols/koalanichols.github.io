Privacy Policy

Agenda Edu Automação · Last updated: 8 November 2026

Agenda Edu Automação is a private tool used by a single person, its developer, to manage school notifications for their own family. This policy explains what Google data it accesses and what happens to it. Back to the home page.

What data the tool accesses

  • Gmail: only messages that the owner has labeled AgendaEdu. The tool does not read the rest of the mailbox.
  • Gmail (sending): it sends summary emails from the owner’s own account to the owner.
  • Google Calendar: it creates events in the owner’s calendar for school items that have a confirmed date.

How the data is used

The text of the labeled emails is analyzed to extract the student, category, summary, dates, deadlines, and links. The results are used only to create calendar events and to produce the daily and weekly summaries. Nothing is used for advertising, profiling, or any purpose unrelated to these features.

Where the data is stored

Extracted information is stored in a local database on the owner’s own computer. It is not uploaded to a public server, website, or shared database. Access tokens are also kept only on that computer.

Who receives the data

  • Google Gemini API: the text of the labeled emails is sent to Google’s Gemini API so it can be summarized and classified.
  • Summary recipients: the resulting summaries are delivered by email and WhatsApp to the owner and to family members the owner has chosen.

The data is not sold, rented, or shared with anyone else.

Google API Services User Data Policy

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Data stays in the local database until the owner deletes it. The owner can delete the database file at any time, and can revoke the tool’s access to the Google account at myaccount.google.com/permissions.

Changes to this policy

If the tool’s behavior changes in a way that affects this policy, this page will be updated and the date above will change.

Questions about this policy: message the developer through the GitHub profile.
